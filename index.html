Multi-Blend Batch Renderer

Render banyak file .blend yang berbeda-beda secara berurutan dan otomatis, tanpa perlu buka & render satu-satu manual.

VIDEO TUTORIAL
SELECTION STRUCTURE
01_CAT.blend
02_CHICKEN.blend
03_DOG.blend
04_RABBIT.blend
Tinggal drag-select beberapa file .blend berbeda lewat file browser,
tiap file dirender sesuai kondisi scene-nya masing-masing.
STEP-BY-STEP
01
Atur render settings (opsional)Aktifkan "Enable Custom Render Settings" buat nge-override engine, device, resolusi, samples, dan noise threshold di semua file sekaligus, tanpa perlu ubah tiap file .blend satu-satu.
02
Tambahkan file .blendKlik "Add Files" di Blend Files to Render, lalu pilih beberapa file .blend berbeda sekaligus lewat file browser.
03
Set output & delayTentuin folder output dan Render Delay di bagian Output Path.
04
Jalankan renderKlik Render buat mulai. Tiap file dibuka otomatis di instance Blender terpisah, dirender, lalu disimpan sebagai PNG dengan nama file yang sama.
05
Batalkan kapan sajaTekan Esc kapan aja buat batalin proses batch render yang lagi jalan.

Asset Workshop

Asset browser lengkap dalam satu panel: object, material, dan HDRI environment.

VIDEO TUTORIAL
ACCESS

Via Sidebar

Buka panel JE di sidebar (tekan N di viewport), lalu buka Asset Workshop buat akses tab Objects, Library, dan Settings.

Via Shift + A

Tekan Shift+A > Hair Base buat langsung nambahin object hair base ke scene tanpa buka panel.

STEP-BY-STEP
01
Pilih tab yang sesuaiAda 3 tab di bagian atas panel: Objects (tambah asset object), Library (material & HDRI), dan Settings (edit parameter material). Klik ikon tab buat pindah.
02
Tambah object dari Objects tabPilih kategori, browse preview object, lalu klik Add Object to Scene.
03
Terapkan material dari Library tabPilih kategori material, browse preview, klik material buat langsung diterapkan ke object aktif.
04
Load HDRI dari Library tabPilih kategori Environment, browse HDRI, klik buat load ke world. Klik nama HDRI-nya buat simpan ke Favorites, biar gampang dipanggil lagi lain kali.
05
Akses HDRI yang udah disaveKlik ikon bintang di sebelah tombol Load HDRI buat buka daftar Favorites, lalu klik nama HDRI yang ada dalam list buat langsung load.
06
Edit parameter material di Settings tabPilih object bermaterial node-group, atur warna, angka, atau rotasi langsung dari panel tanpa buka Shader Editor.

Light Mask

Isolasi lampu ke object atau collection tertentu pakai Light Linking, tanpa ribet ngatur manual.

VIDEO TUTORIAL
ACCESS

Via Sidebar

Buka panel JE di sidebar (tekan N di viewport), lalu buka Light Mask buat kelola semua lampu terhubung dari list.

Via Shortcut F (Object)

Tekan F saat object biasa aktif buat lihat lampu mana aja yang nge-link ke object itu, lengkap dengan ikon trash buat unlink.

Via Shortcut F (Lighting)

Tekan F saat lampu aktif buat buka quick menu setting light mask-nya: ganti target Object/Collection, toggle shadow, dan rename.

STEP-BY-STEP
01
Buat light mask baruSeleksi object yang mau dimasking, lalu tekan Shortcut F. Lampu baru otomatis dibuat dan langsung tracking ke object itu.
02
Link lampu yang sudah adaSeleksi lampunya dulu, lalu seleksi object yang mau dilink (biar jadi aktif). Tekan Shortcut F dan klik Link Existing Light buat hubungin lampu itu ke object tersebut.
03
Kombinasikan dengan Shortcut DSetelah masking atau link selesai, tekan D di lampunya buat buka Quick Menu Light Settings, atur power, warna, dan setting lain secara cepat.
04
Toggle shadow linkingKlik ikon shadow di samping nama lampu, dipakai kalau ada area object yang shadow-nya nggak diinginkan.
05
Ganti targetPilih mode Object atau Collection di tiap entry buat ganti target masking-nya.

Trinity Lighting

Setup three-point lighting otomatis yang langsung tracking ke objek pilihan.

VIDEO TUTORIAL
ACCESS

Via Sidebar

Buka panel JE di sidebar (tekan N di viewport), lalu klik tombol Trinity Lighting.

Via Shortcut Shift + A

Tekan Shift+A > Light > pilih Trinity Lighting.

STEP-BY-STEP
01
Pilih objek targetSeleksi object yang mau jadi pusat pencahayaan (semua lampu bakal otomatis tracking ke object ini).
02
Spawn Trinity LightingKlik tombol Trinity Lighting di panel, atau lewat Shift+A > Light > Trinity Lighting.
03
Atur tiap lampu secara cepatSeleksi salah satu lampu, tekan D buat buka Quick Menu Light Settings, bisa atur nama lighting, power, warna, type lighting, shape, dan target tracking-nya.
04
Solo mode buat fokus 1 lightingKlik ikon mata di lampu yang mau dicek sendirian, biar lampu lain sementara disembunyikan dari viewport.

Modeling Toolkit

Kumpulan tool modeling harian dalam satu panel: cleanup, mirror, subdivision, dan solidify.

VIDEO TUTORIAL
ACCESS

Via Sidebar

Buka panel JE di sidebar (tekan N di viewport), lalu buka Modeling Toolkit buat akses semua tool lengkap.

Via Shortcut D

Tekan D di viewport buat buka Quick Menu, akses cepat ke Cleanup, Mirror, Subdivision, dan Solidify.

STEP-BY-STEP
01
Cleanup sceneBuka Cleanup, klik Unused Materials dan Unused Empty buat bersihin material dan empty yang gak kepakai.
02
Add mirror modifierBuka Mirror Tools, pilih mode Half Object atau Separate Object, atur axis, lalu klik Add Mirror. Bisa juga pilih object custom lewat Mirror Object Picker sebagai pivot.
03
Half ObjectMirror dari Origin, hasilnya 1 object utuh (perlu dipotong setengah dulu, menyesuaikan axis yang dipilih).
04
Separate ObjectMirror dari 3D Cursor, hasilnya 2 object terpisah (contoh: ban mobil).
05
Atur subdivisionBuka Subdivision Tools, atur level Viewport dan Render, lalu klik Add Subsurf atau Apply Subsurf.
06
Solidify objectBuka Solidify Tools, klik Add Solidify buat nambahin ketebalan otomatis, atau Apply Solidify buat langsung diterapkan.

Saved Light Presets

Simpan setup lighting kamu sendiri jadi preset yang bisa dipanggil ulang kapan aja.

VIDEO TUTORIAL
ACCESS

Via Sidebar

Buka panel JE di sidebar (tekan N di viewport), lalu buka Saved Light Presets buat kelola semua preset dari list.

Via Shortcut Shift + A

Tekan Shift+A > Light Preset > pilih preset buat langsung ditambahin ke scene.

STEP-BY-STEP
01
Tambah preset baruKlik Add New Preset, isi Preset Name, pilih file .blend sumber, dan nama collection lighting-nya.
02
Cek nama collectionKlik Checking buat lihat daftar collection berisi light di file .blend itu, lalu masukin nama collection yang sesuai ke kolom Lighting Collection Name.
03
Apply preset ke scenePilih preset dari list, lalu klik Add Lighting to Scene.
04
Hapus presetKlik ikon minus di samping nama preset dalam list buat menghapusnya dari daftar secara permanen.
